# everyday-git-for-OMAs
Resources for the [PSU MacAdmins 2026](https://macadmins.psu.edu) session: [Everyday Git for Overworked MacAdmins](https://psumac2026.sched.com/event/2NBpU/everyday-git-for-overworked-macadmins)

Feeling like your script versions have gotten out of control? Struggling to share the load with different admins? Wondering where the heck to store process documents? Come see how I solved these problems -- and more! -- with git and GitHub/GitLab.
